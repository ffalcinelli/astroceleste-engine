# Architecture

## Crates

| Crate | Role | Published to |
|---|---|---|
| `crates/astroceleste-engine` | the core library: everything that computes | crates.io |
| `crates/astroceleste-engine-py` | Python bindings (PyO3, built with maturin) | PyPI |
| `crates/astroceleste-engine-wasm` | WebAssembly bindings (wasm-bindgen, built with wasm-pack) | npm |

The bindings are thin. They build a `KernelSet`, call the core entry points and pass results
across as JSON (`serde_json` with `preserve_order` and `float_roundtrip`). Floats stay exact,
and the shape a binding returns is the Rust `Serialize` output, which is also the JSON of the
Astroceleste API. The one crate shares a single version with both packages.

The core has only two dependencies (`serde`, `serde_json`), no C code and no
platform-specific I/O, so it builds for servers, desktop, `wasm32-unknown-unknown`, Android
and iOS.

## The pipeline

```text
                UtcInstant, lat, lon, options (ChartRequest)
                                  │
   time.rs ─────── UT1 / TT / TDB, ΔT (embedded data/deltat.bin)
                                  │
   ephemeris/ ──── spk.rs      read JPL SPK kernels (file or bytes), Chebyshev states
                   kernels.rs  KernelSet: first kernel covering the date wins, else OutOfRange
                   observe.rs  apparent geocentric positions: light-time, deflection, aberration
                                  │
   frames/ ─────── precession, nutation, sidereal time → true ecliptic of date
                                  │
   planets.rs ──── planets, mean nodes, Chiron (chiron.rs, data/chiron.bin), Lilith
                                  │
   houses.rs ───── cusps, Ascendant, Midheaven      zodiac.rs ── signs, ayanamsas, sidereal
                                  │
   aspects.rs · fixed_stars.rs · lots.rs · temperament.rs · lunar.rs
                                  │
   chart.rs ────── calculate_chart → Chart
                                  │
   horary.rs ───── + planetary hours (almanac.rs sunrise/sunset), significators, strictures
   derived.rs ──── transits, synastry, derived charts on top of calculate_chart
   election.rs ─── electional score of a moment; search over a span (interpolated between
                   hourly exact positions, sunrises found once for the span)
```

Supporting modules:

- `instant.rs`: UTC instants with microsecond resolution and Python `datetime` semantics
  (ISO formatting, float-day arithmetic).
- `pyfloat.rs`: Python `%`, `//`, `divmod` and `round()`. See [Accuracy](accuracy.md).
- `symbolic.rs`: symbolic (1–30) degree numbering.
- `catalog/`: static tables (fixed stars, lunar mansions, derived-house meanings). This is
  generated code, excluded from rustfmt and clippy.
- `constants.rs`: the constants used by Skyfield 1.55 and the reference implementation.

Each module's doc comment names the reference function it ports (for example
`charts/calc/aspects.py` or `SkyfieldEngine.calculate_houses`), so the two implementations
can be compared side by side.

## Generated data

| File | Generated by |
|---|---|
| `src/data/deltat.bin` (ΔT), `src/data/chiron.bin` (Chiron longitudes), `src/frames/nutation_data.rs` (IAU 2000A terms) | `scripts/gen_tables.py` |
| `tests/data/de440s_2000.bsp`, `tests/fixtures/spk_reference.json` | `scripts/make_spk_fixtures.py` (jplephem) |
| `tests/fixtures/reduction.json` | `scripts/make_reduction_fixtures.py` (Skyfield) |
| `tests/fixtures/{natal,horary,…}.json` | the reference implementation |

None of these is edited by hand.

## Public API

The API is curated. Every module is private except `ephemeris`, and `lib.rs` re-exports the
entry points, `ChartRequest`, `EngineError`, `UtcInstant` and every type reachable from a
result. `time`, `frames` and `ephemeris::observe` are public but hidden from the docs, only
so that the stage-by-stage test (`tests/reduction.rs`) can reach them. They are not part of
the API.

## Website

`site/` holds the static landing page and the live demo. `scripts/build-site.sh` assembles
it into `target/site/` with the WebAssembly package (`wasm-pack --target web`) and a
1950–2050 DE440s excerpt, and `.github/workflows/pages.yml` deploys it to GitHub Pages.
